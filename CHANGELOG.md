# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-07

### Added

- Skills: `jobhunt-profile`, `jobhunt-decode`, `jobhunt-resume`,
  `jobhunt-cover-letter`, `jobhunt-interview`, `jobhunt-negotiate`,
  `jobhunt-followup`, `jobhunt-tracker`.
- Agents: `recruiter-screen`, `hiring-manager`, `bar-raiser`,
  `resume-truth-checker`.
- Helper scripts (Python standard library only): `ats_match.py` keyword
  coverage, `offer_compare.py` total-comp comparison, `tracker.py`
  application tracker.
- Unit tests for every script and a repository structure test.
